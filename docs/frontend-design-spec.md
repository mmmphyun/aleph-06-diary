# T06 플랜두씨 다이어리 UI/UX 및 인터랙션 상세 명세서

> 본 문서는 외부 비주얼 레퍼런스 없이도 개발자가 오차 없이 구현할 수 있도록 모든 뷰의 레이아웃, 정적 상태의 시각 규격, 그리고 상황별 2.5D 애니메이션 물리값을 정의한 프런트엔드 설계 명세서입니다.

## 1. 글로벌 레이아웃 및 뷰포트 아키텍처

### 1.1 데스크 컨테이너 (Canvas)
* **뷰포트**: `min-h-screen w-full bg-[#EFECE6] flex items-center justify-center p-4 md:p-8 select-none`
* **데스크 질감**: 무채색 웜그레이 매트 텍스처. 채도 높은 원목 패턴 배제하고 부드러운 주변광 그림자(`radial-gradient`) 적용.
* **원근감 컨테이너**: `perspective-[1400px]` 설정으로 3D 회전 시 자연스러운 원근 투영 생성.

### 1.2 다이어리 바인더 (Book Chassis)
* **외형 규격**: 가로 960px × 세로 640px (1.5:1 가로형 양장 바인더 비율, 모바일은 100% 폭 적응).
* **커버/테두리**: 하드커버 두께 4px, 둥근 모서리 `rounded-2xl`, 다크 차콜 매트 레더 톤(`bg-[#242220]`), 섀도우 `shadow-[0_25px_50px_-12px_rgba(0,0,0,0.35)]`.
* **중앙 제본선 (Spine/Crease)**:
  * 폭 16px의 중앙 접힘선 (`bg-gradient-to-r from-stone-300 via-stone-400 to-stone-200 opacity-60`).
  * 속지가 안쪽으로 휘어 들어가는 깊이감 표현 (`shadow-[inset_0_0_15px_rgba(0,0,0,0.15)]`).

## 2. 뷰(View)별 정적 레이아웃 및 시각 규격

### View 0: 다이어리 표지 (Cover View - 닫힌 상태)
* **역할**: 진입 첫 화면. 로그인 없음 안내 및 다이어리 열기 진입점.
* **배치**:
  * **표지 본체**: `w-[480px] h-[640px] bg-[#242220] rounded-r-2xl border-l-4 border-stone-800 p-10 flex flex-col justify-between`.
  * **음각 타이틀**: `Plan-Do-See Diary` 금박/은박이 아닌 정갈한 은은한 음각 텍스트 (`text-stone-400 tracking-widest font-mono text-sm uppercase`).
  * **중앙 금속 잠금쇠 (Open Padlock)**:
    * 촌스러운 클립아트 배제. 정밀한 2px 라인의 미니멀 메탈 일러스트 (`lucide: LockKeyholeOpen`, 48px, 메탈릭 브러시드 실버 톤 `text-stone-300`).
    * 고리가 위로 비스듬히 풀려 있는 형태.
  * **필수 안내 포스트잇 (Notice Memo)**:
    * 잠금쇠 하단에 반투명 마스킹 테이프로 부착된 페일 옐로우 포스트잇 (`bg-[#FFFDE7] text-stone-800 text-xs p-4 rounded-sm shadow-md rotate-[-2deg] border border-amber-200/60`).
    * **표시 문구 (필수)**:
      > `지금은 로그인이 없어 링크를 아는 사람은 누구나 볼 수 있습니다. 남이 봐도 괜찮은 내용만 넣으세요`
  * **열기 버튼**: 포스트잇 우측 하단 "다이어리 열기 →" 텍스트 힌트.

---

### View 1: 돌아보기 (See / Review - 펼쳤을 때 첫 내지)
* **역할**: 다이어리를 펼쳤을 때 나타나는 2면(좌/우) 통합 뷰.
* **좌측 페이지 (기간 및 집계 요약 카드)**:
  * **상단 날짜 선택기**:
    * 캘린더 아이콘과 함께 `YYYY-MM-DD ~ YYYY-MM-DD (KST)` 범위 표기.
    * 클릭 시 미니멀 날짜 선택 팝오버 노출.
  * **4대 핵심 지표 카드 (2×2 그리드)**:
    1. **계획 수**: 수치 + '개' 레이블 (`hover:border-stone-400 cursor-pointer`).
    2. **완료 수**: 수치 + '개' 레이블 (포인트 컬러 `text-emerald-700`).
    3. **실행 기록 수**: 수치 + '건' 레이블.
    4. **평균 시간 차이**: `±X분` (예상 대비 지연/단축 여부, `text-amber-800`).
    * 각 카드는 1px 보더(`border-stone-200 bg-white/70 rounded-lg p-4 shadow-sm`).
    * 하단에 작은 안내 텍스트: *"숫자를 클릭하면 해당 기록 목록으로 이동합니다"*
* **우측 페이지 (집계 세부 분석 뷰)**:
  * 좌측 카드 클릭 시 해당 조건의 목록(선택 기간 계획 목록, 완료된 할 일 목록, 실행 기록 타임라인, 시간 오차 분석표)이 즉시 렌더링.
  * 기본 상태: 선택 기간 전체의 시간 배분 요약 막대그래프 및 최근 완료 기록 3건.

---

### View 2: 계획 세우기 (Plan View)
* **좌측 페이지 (현재 활성 계획 카드)**:
  * **상단 메타 바**: 계획 제목 (`text-xl font-semibold text-stone-900`), 우선순위 뱃지(높음: 레드틴트, 보통: 앰버틴트, 낮음: 슬레이트틴트).
  * **기간**: `2026.10.01 ~ 2026.10.31` (캘린더 뱃지).
  * **예상 총 시간**: `48시간 (2,880분)`.
  * **성공 기준 (Success Criteria)**: 연한 줄노트 배경 위 체크박스 리스트 형태의 텍스트.
  * **조작부**: 우측 상단 '계획 수정' 연필 아이콘 버튼.
* **우측 페이지 (수정 이력 타임라인)**:
  * **제목**: `수정 이력 (Revision History)` + 총 이력 건수.
  * **목록 규격**: 페이지당 5건 고정 페이지네이션.
  * **스냅샷 카드**:
    * 수정 시점 타임스탬프 (`YY.MM.DD HH:mm`).
    * 변경 전 값에 **취소선(`line-through text-stone-400`)** 적용 및 신규 값 인라인 대조.
    * 불변 스냅샷임을 나타내는 작은 스탬프 테두리.

---

### View 3: 할 일 다루기 (Do / Tasks View)
* **상단 고정 컨트롤러 (인덱스 메모지 규격)**:
  * **검색창**: 미니멀 돋보기 아이콘 + 플레이스홀더 `"할 일 제목, 설명 검색..."`.
  * **필터 셀렉터**: 상태(전체/진행 전/진행 중/완료), 우선순위(전체/높음/보통/낮음), 마감일.
  * **정렬 공시 배너 (T06-C20 필수)**:
    * 검색창 하단 1px 보더 박스: `"정렬 기준: 마감일 오름차순 → 우선순위(높음 우선) → 제목 가나다순 → ID순"`
* **할 일 카드 (양면 펼침 그리드, 1열 카드 목록)**:
  * **헤더**: 상태 토글 스티커 버튼 + 제목 + 우선순위 라벨.
  * **바디**: 설명문 2줄 요약(클릭 시 확장), 마감일시(`YY.MM.DD 23:30`), 태그 칩(`bg-stone-100 text-stone-600 rounded px-2 py-0.5 text-xs`).
  * **푸터 액션**:
    * '실행 기록 작성' 버튼 (`+ 기록`).
    * '삭제' 버튼 (휴지통 아이콘).
* **실행 기록 모달 (Dialog)**:
  * 시작 일시, 종료 일시 입력 필드 (기본값 현재 시각).
  * 실시간 계산 시간 표시: `실제 걸린 시간: 1시간 45분 (105분)`.
  * 막혔던 이유 텍스트 에어리어 (선택 입력).

---

### View 4: 휴지통 (Trash View)
* **목록 표현**: 삭제된 할 일 및 계획 카드.
* **시각 효과**: 구겨진 종이 텍스처 음영 + 상단에 사선으로 붙은 반투명 마스킹 테이프.
* **액션**: '복구' 버튼 (클릭 시 테이프가 떨어지는 애니메이션과 함께 활성 상태 `trashStatus: 2`로 전환).
* **상단 배너**: `"휴지통의 항목은 7일 동안 보관 후 안전하게 영구 삭제됩니다."`

## 3. 상황별 애니메이션 및 물리 인터랙션 스펙

모든 3D 변형은 브라우저 Compositor Thread에서 처리되도록 `transform`과 `opacity`만 조작합니다. (Layout Reflow 발생 0%).

| 트리거 / 상황 | 애니메이션 명칭 | CSS 속성 및 트랜지션 스펙 | 시각적 메커니즘 및 디테일 |
|---|---|---|---|
| **다이어리 열기** (표지 클릭) | **Cover Unfold 3D** | `transform: rotateY(-180deg)`<br>`transform-origin: left center`<br>`transition: transform 700ms cubic-bezier(0.16, 1, 0.3, 1)` | 표지가 왼쪽으로 젖혀지며, 0°~90° 구간에서 표지 뒷면 그림자 `opacity` 0.4까지 증가 후 90°~180°에서 0으로 소멸. 속지가 드러남. |
| **다이어리 닫기** (표지 닫기 버튼) | **Cover Fold 3D** | `transform: rotateY(0deg)`<br>`transition: transform 600ms cubic-bezier(0.2, 0, 0, 1)` | 역방향으로 덮이며 완료 시 바인더가 탁 닫히는 미세한 2px 수직 바운스. |
| **탭 이동** (우측 인덱스 클릭) | **Page Curl Flip** | `transform: rotateY(-180deg)`<br>`transform-origin: left center`<br>`transition: transform 450ms ease-out` | 현재 우측 페이지가 책장 넘어가듯 왼쪽으로 넘어가며 새 페이지 렌더링. 넘김 중 텍스트 인풋 포커스 비활성화. |
| **할 일 완료 버튼 클릭** | **Stamp / Check Spring** | `transform: scale(0.9) -> scale(1.05) -> scale(1)`<br>`transition: all 250ms cubic-bezier(0.34, 1.56, 0.64, 1)` | 연초록 체크 스티커가 쿵 찍히는 듯한 햅틱 바운스. 완료 즉시 중복 클릭 차단(버튼 비활성화 및 트랜잭션). |
| **할 일 삭제 클릭** | **Paper Tear & Fade** | `clip-path: polygon(...)`<br>`opacity: 1 -> 0`<br>`transform: translateY(8px)` (300ms) | 카드의 우측 모서리가 지그재그(찢어진 모양)로 잘려 나가며 아래로 부드럽게 페이드아웃. |
| **휴지통 항목 복구** | **Tape Peel & Unfold** | 마스킹 테이프 회전 각도 0° 환원 후 본문 투명도 복원 (350ms) | 구겨졌던 음영이 펴지며 일반 카드 테두리로 정돈. |
| **데이터 저장 중** (Firestore Write) | **Pen Scribble Pulse** | 만년필 닙(Nib) 아이콘이 좌우 ±3px, 각도 ±5° 미세 흔들림 (Infinite 1s) | 헤더 우측에 "기록 중..." 인디케이터가 펜촉 드로잉 모션과 함께 점멸. |
| **오류 발생** (네트워크/DB 실패) | **Coffee Splash Reveal** | 둥근 원형 그라디언트 스플래시 SVG의 `scale(0.8 -> 1)` + `opacity(0 -> 0.8)` (400ms) | 우측 상단 또는 카드 모서리에 옅은 세피아 커피 링 얼룩이 배어나오며, 그 위에 명확한 고대비 에러 문구 팝업 노출. |

## 4. 정적 상태 규격 (Empty / Loading / Error)

### 4.1 빈 상태 (Empty State)
* **화면**: 아무 계획이나 할 일이 등록되지 않은 상태.
* **레이아웃**:
  * 완벽하게 깨끗한 오프화이트 모눈종이 텍스처 중앙에 연필 드로잉 스타일의 노트 아이콘.
  * 헤드라인: `"아직 작성된 계획이 없습니다"` (`text-stone-500 font-medium text-base`).
  * 서브라인: `"새 계획을 세우고 실제 실행과의 오차를 기록해보세요."`
  * CTA 버튼: `[ + 첫 계획 세우기 ]` (미니멀 1px 보더 버튼).

### 4.2 오류 상태 (Error State)
* **원칙**: 장식(커피 얼룩) 때문에 텍스트가 가려지거나 판독이 불가능해서는 안 됨.
* **레이아웃**:
  * 배경에 반투명 커피 링 워터마크 (`mix-blend-multiply opacity-20 pointer-events-none`).
  * 전경: 굵은 루비레드 1px 보더의 에러 박스 (`bg-white/95 p-6 rounded-lg shadow-lg border border-red-200`).
  * 에러 코드 및 한글 기술: `"데이터를 불러오지 못했습니다: [오류 내용]"` + `[ 다시 시도 ]` 버튼.

## 5. 입력 및 XSS 보안 렌더링 규약 (T06-C57 대응)

* 모든 사용자 입력 문자열(계획 제목, 성공 기준, 할 일 제목/설명, 막혔던 이유 등)은 DOM에 삽입 시 **텍스트 노드(Text Node)로만 렌더링**합니다.
* React 기준 `{text}` 바인딩만 허용하며, `dangerouslySetInnerHTML`의 사용을 원천 금지합니다.
* 사용자가 `<script>alert(1)</script>`을 입력하여 저장하면 화면에는 해당 태그가 실행되지 않고 문자열 그대로 표시됩니다.
