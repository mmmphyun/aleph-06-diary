## 1. [M1] 다이어리 표지와 골격 필수 검증 항목 (현재 작업)

- [ ] **표지 안내 메모 (T06-C82)**:
  `"지금은 로그인이 없어 링크를 아는 사람은 누구나 볼 수 있습니다. 남이 봐도 괜찮은 내용만 넣으세요"` 토씨 하나 틀리지 않고 렌더링되었는가?
- [ ] **바인더 섀시 규격**:
  960×640px (1.5:1 비율) 고정 규격으로 유지되며, 반응형 레이아웃 분기가 강제 주입되지 않았는가?
- [ ] **데스크 캔버스 환경**:
  무채색 웜스톤(`bg-[#EFECE6]`), 최소 너비 `min-w-[960px]`, 저급 원목/가죽 텍스처를 쓰지 않았는가?
- [ ] **잠금쇠 일러스트**:
  정밀한 2px 메탈 라인(`LockKeyholeOpen`)으로 렌더링되며, 3D 클립아트가 배제되었는가?
- [ ] **개인화 툴바 및 로컬 스토리지 연동**:
  - 4종 테마 전환 시 `colors.json` 토큰이 즉시 CSS 변수에 반영되고 `localStorage('diary_theme')`에 저장되는가?
  - 3종 손글씨 폰트 전환이 동작하며 `localStorage('diary_font_preference')`에 즉시 보존되는가?
- [ ] **타이포그래피 및 폰트 로딩**:
  - 시스템 데이터/UI(버튼, 타이틀, 시스템 메시지)는 `font-mono`/`font-sans`를 사용하는가?
  - 사용자 필기 영역(표지 메모 문구)에만 손글씨 폰트가 적용되는가?
  - `@font-face`에 `font-display: swap;`이 선언되어 렌더링 블로킹을 방지하는가?
- [ ] **2.5D 인터랙션 및 상태**:
  - 표지 열기(`rotateY(-180deg)`, 700ms)가 GPU 합성 스레드에서 부드럽게 동작하는가?
  - 회전 중 `pointer-events-none`이 적용되어 클릭 및 오동작이 차단되는가?
  - 3대 상태 뷰(Empty 모눈종이, Loading 만년필 닙 흔들림, Error 커피 얼룩+고대비 박스)가 각각 올바르게 렌더링되는가?
- [ ] **보안 렌더링 기본 원칙 (T06-C57)**:
  - 모든 텍스트는 React Text Node(`{text}`)로만 삽입되고 `dangerouslySetInnerHTML`이 배제되었는가?
