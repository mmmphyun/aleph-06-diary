# STORYBOARD.md — 바인더 아키텍처 및 물리 키프레임 정본 (SSOT)

> 본 문서는 실제 양장 바인더 다이어리의 물리적 개폐 법칙, 인덱스 탭 2-Tier 구조, 달력 기반 속표지(TOC), 섹션별 고유 넘버링, 동적 속지 스택(Dynamic Leaf Stack), 라이프사이클 전제조건 게이트, 아날로그 인라인 취소선 수정을 규정하는 정본(SSOT) 시각 스토리보드입니다.

---

## 1. 다이어리 시스템 아키텍처 개요

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           2-Tier 바인더 탐색 구조                               │
│                                                                                 │
│ [바인더 베이스 (바닥 고정)]                                                     │
│   ├─ 좌측 바닥: Inside Cover (소유자 서명) - 표지 열기 후 영구 고정             │
│   └─ 우측 바닥: 뒷표지 안쪽 (Back Inside Cover)                                 │
│                                                                                 │
│ [속지 레이어 (오직 속지만 좌우 플립)]                                           │
│   └─ 우측 돌출 인덱스 탭 (대분류 섹션 전환 ➔ Page Flip Cascade 모션)             │
│        ├─ [ 탭 1: 기록 캔버스 (Writing) ] ➔ 순수 빈 속지들 (계획 / 할일 / 실행) │
│        │     - 넘버링 프리픽스: PLAN 01, PLAN 02 ... (또는 CH.01 P.01)          │
│        ├─ [ 탭 2: 돌아보기/통계 (Review) ] ➔ REVIEW 01, REVIEW 02 ...           │
│        └─ [ 탭 3: 보관/휴지통 (Archive) ] ➔ ARCHIVE 01, ARCHIVE 02 ...          │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 1.1 물리 불변식
1. **표지 플립과 속지 플립의 엄격한 분리**:
   - 앞표지 회전: 다이어리를 닫힌 상태에서 처음 열 때 단 1회만 발생 (`rotateY(-180deg)`). 이후 앞표지는 좌측 바닥에 영구 고정.
   - 속지 회전: 본문 내 모든 페이지 넘김은 **오직 흰색 속지(Paper Leaf)들만 중앙 제본선(X=480px) 축으로 좌우 회전 (280ms)**.
2. **2-Tier 탐색 체계**:
   - **대분류 (우측 돌출 인덱스 탭)**: [기록] / [통계] / [보관] 탭 클릭 시, 넘겨진 속지들이 한 묶음으로 빠르게 넘어가는 **캐스케이드 플립(Page Flip Cascade)**으로 해당 섹션 첫 장으로 이동.
   - **소분류 (속지 플립)**: 각 섹션 내부에서 넘쳐난 빈 페이지들을 앞뒤로 넘기는 물리 조작.
3. **무스크롤(No-Scroll) 절대 원칙**:
   - 960×640px 바인더 판면 내부의 어떠한 컴포넌트(속표지, 텍스트 에디터, 할 일, 실행 일지)에서도 브라우저 스크롤바 발생을 전면 금지함.
   - 공간 초과 시 스크롤 대신 새로운 속지(Spread)를 물리적으로 추가하여 페이지를 넘김.
4. **섹션별 고유 넘버링 체계**:
   - 획일적인 `PAGE 00` 번호 매김 폐지.
   - 기록 섹션: `PLAN 01`, `PLAN 02`...
   - 돌아보기 섹션: `REVIEW 01`, `REVIEW 02`...
   - 보관함 섹션: `ARCHIVE 01`, `ARCHIVE 02`...
5. **아날로그 인라인 취소선 수정 (최대 1회 교정 원칙)**:
   - 별도 수정 이력 타임라인 팝업 폐지.
   - 원문 드래그 ➔ 만년필 교정 버블 ➔ 원문에 만년필 취소선(`line-through`) ➔ 바로 아래 18px 여백선에 버건디 손글씨 교정문 기재.

## 2. 속표지(Leaf 01): 달력 기반 목차 (TOC) 시스템

```
┌────────────────────────────────────────────────────────┐
│ [속표지: Table of Contents (480×640px)]                 │
│                                                        │
│ [상단: 시스템 헤더 & 타이틀]                           │
│   ALEPH-06 PLAN-DO-SEE / TABLE OF CONTENTS             │
│                                                        │
│ [중앙 상단: 미니 월간 달력 (Mini Calendar)]            │
│   - 기본값: 시스템 현재 연월/오늘 날짜 선택            │
│   - 각 날짜 셀: 날짜 숫자 + 해당일 계획 건수 뱃지 (예: 2)│
│   - 날짜 클릭 시 선택 상태 동기화                     │
│                                                        │
│ [중앙 하단: 해당 날짜 계획 목록 (선택일 필터링)]        │
│   - 조건: period.start <= 선택일 <= period.end         │
│   - 각 계획 카드: 챕터 번호, 제목, 상태 뱃지,          │
│     동적 페이지 범위 표기 (예: PLAN 01 ~ PLAN 04)      │
│   - 무스크롤 유지 (선택일 기준 제한된 건수만 표출)     │
│                                                        │
│ [하단: 2-Way 액션]                                     │
│   - [+ 새 계획 추가 (해당 날짜)]                       │
│   - [선택한 계획으로 속지 넘기기 →]                     │
└────────────────────────────────────────────────────────┘
```

- **달력 매핑 기준**: **방안 B (실행 예정 기간 `period: { start, end }` 범위 매핑)**.
- **페이지 범위 동적 계산**: 각 계획의 (계획 스프레드 수 + 할 일 스프레드 수 + 일지 유무)를 실시간 합산하여 TOC에 `PLAN XX ~ PLAN YY` 정확히 출력.

## 3. 동적 속지 스택 및 라이프사이클 전제조건 게이트

```
[계획 (Plan)] (14줄/스프레드)
  ├─ 텍스트 에디터: 좌 7줄 + 우 7줄 (무스크롤)
  ├─ 우측 7행 포화 시 키 입력: 강제 플립 배제, "현재 장 가득 참" 가이드 툴팁 표출
  └─ 라이프사이클:
       ├─ draft: 자유 텍스트 편집 가능 / [계획 확정 날인] 버튼 대기
       └─ confirmed (확정 날인 완료):
             ├─ 본문 편집/삭제 완전 잠금 (Readonly)
             └─ 오직 [만년필 1회 교정]만 허용
                   ↓ (다음 장 넘김)
[완전한 빈 속지 (Blank Leaf)]
  ├─ draft 상태일 때: [계획 속지 추가]만 허용 (할 일 템플릿 비활성화)
  └─ confirmed 상태일 때: [할 일 체크리스트 템플릿 날인] 해금
        ↓ (서식 날인 완료)
[할 일 (Tasks)] (14개/스프레드)
  ├─ 좌 7개 + 우 7개 고정 배치 (무스크롤)
  ├─ 14개 초과 시: 자동으로 '할 일 스프레드 2', '스프레드 3'으로 다중 분할
  └─ 완료 항목 1개 이상 존재 시: [실행 일지] 속지가 바인더 스택에 결속
        ↓ (다음 장 넘김)
[실행 일지 (Logs)] (14개/스프레드)
  ├─ 완료된 할 일 타임스탬프와 한 줄 소회 코멘트 잉크 기재
  └─ 바인더 맨 마지막: [+ 다음 계획 바인더에 결속] 연속성 진입 버튼 배치
```

## 4. 새 계획 추가 2-Way 진입점

1. **경로 1 (연속성: In-Binder Continuity)**:
   - 현재 계획 패키지의 마지막 속지(실행 일지 또는 백지) 우측 하단에 `[+ 다음 계획 바인더에 결속 →]` 버튼 배치.
   - 클릭 시 다음 계획 패키지가 생성되며 280ms 3D 플립으로 새 계획의 첫 스프레드로 연속 전개.
2. **경로 2 (편의성: Direct TOC Registration)**:
   - 속표지(Leaf 01) 달력 하단에 `[+ 새 계획 등록]` 버튼 배치.
   - 현재 선택된 달력 날짜를 `period.start`/`end`로 자동 지정하여 신규 패키지 즉시 생성 및 선택.

|---|---|---|---|

| **교정 여백선 (Correction Line)** | `font-handwriting` | 12~13px / line-height 18px | `#991B1B` (교정 잉크 레드) |
| **시스템 라벨 / 버튼** | `font-sans` (Pretendard) | 11~13px | `#57534E` / `#1C1917` |
| **타임스탬프 / 날짜 / 인덱스** | `font-mono` | 10~11px | `#78716C` |
