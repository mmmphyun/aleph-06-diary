# STORYBOARD.md — 바인더 아키텍처 및 물리 키프레임 정본 (SSOT)

> 본 문서는 실제 양장 바인더 다이어리의 물리적 개폐 법칙, 인덱스 탭 2-Tier 구조, 양면 빈 캔버스, 아날로그 인라인 취소선 수정을 규정하는 정본(SSOT) 시각 스토리보드입니다.

---

## 1. 다이어리 시스템 아키텍처 개요

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           2-Tier 바인더 탐색 구조                               │
│                                                                                 │
│ [바인더 베이스 (바닥 고정)]                                                     │
│   ├─ 좌측 바닥: Inside Cover (소유자 서명) - 표지 열기 후 영구 고정             │
│   └─ 우측 바닥: 뒷표지 안쪽 (Back Inside Cover)                                 │
│                                                                                 │
│ [속지 레이어 (오직 속지만 좌우 플립)]                                           │
│   └─ 우측 돌출 인덱스 탭 (대분류 섹션 전환 ➔ Page Flip Cascade 모션)             │
│        ├─ [ 탭 1: 기록 캔버스 (Writing) ] ➔ 순수 빈 속지들 (계획 / 할일 / 실행) │
│        ├─ [ 탭 2: 돌아보기/통계 (Review) ]                                      │
│        └─ [ 탭 3: 보관/휴지통 (Archive) ]                                       │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 1.1 물리 불변식
1. **표지 플립과 속지 플립의 엄격한 분리**:
   - 앞표지 회전: 다이어리를 닫힌 상태에서 처음 열 때 단 1회만 발생 (`rotateY(-180deg)`). 이후 앞표지는 좌측 바닥에 영구 고정.
   - 속지 회전: 본문 내 모든 페이지 넘김은 **오직 흰색 속지(Paper Leaf)들만 중앙 제본선(X=480px) 축으로 좌우 회전**.
2. **2-Tier 탐색 체계**:
   - **대분류 (우측 돌출 인덱스 탭)**: [기록] / [통계] / [보관] 탭 클릭 시, 넘겨진 속지들이 한 묶음으로 빠르게 넘어가는 **캐스케이드 플립(Page Flip Cascade)**으로 해당 섹션 첫 장으로 이동.
   - **소분류 (속지 플립)**: 각 섹션 내부에서 넘쳐난 빈 페이지들을 앞뒤로 넘기는 물리 조작.
3. **양면 빈 종이(Clean Canvas) 캔버스**:
   - 하드코딩된 분할 폼 폐지. 양면(좌 480px + 우 480px) 모두 깨끗한 빈 줄노트로 시작.
   - 줄노트는 **[1줄 본문 기재선(16px 먹색) + 1줄 교정 여백선(12~13px 버건디)]**의 고정 격줄 구조.
4. **아날로그 인라인 취소선 수정 (최대 1회)**:
   - 별도 수정 이력 타임라인 뷰 폐지.
   - 원문 드래그 ➔ 확인 ➔ 원문에 만년필 취소선(`line-through`) ➔ 바로 아래 여백선에 수정 기재. 하단 텍스트 밀림 없음.

## 2. 기록 캔버스 3대 섹션 전개 흐름 (Writing Canvas Lifecycle)

```
[섹션 1: 계획 (Plan)]
  - 양면 빈 줄노트에서 시작
  - 계획 제목 및 본문 자유 기재
  - 안전 글자 수(면당 약 250~280자) 초과 시 우측/다음 속지로 자연스럽게 흐름(Text Flow)
        ↓
  [+ 새 장 넘겨 할 일 작성] 수동 액션
        ↓
[섹션 2: 할 일 (Tasks)]
  - 계획 종료 위치와 무관하게, 항상 '새로운 빈 속지(새 장)'를 넘겨서 시작
  - [+ 할 일 템플릿] 버튼으로 체크리스트 블록 추가 (양면 수용 가능)
        ↓
  [+ 새 장 넘겨 실행 일지] 수동 액션
        ↓
[섹션 3: 실행 기록 (Logs)]
  - 할 일 목록 종료 후, 다음 '새로운 빈 속지(새 장)'에 일지 캔버스 마련
  - 유저가 할 일을 체크 완료할 때마다 타임스탬프와 손글씨 코멘트가 잉크처럼 한 줄씩 순차 누적
```

## 3. 물리 키프레임 상세 (Keyframes)

### Frame 0: 닫힘 상태 (Closed)
* **좌측 480×640px**: 웜스톤 데스크 바탕 위의 독립형 데스크 메모지 (`DeskMemoSheet` - 철학 명언 기재).
* **우측 480×640px**: 닫힌 1권의 검은 하드커버 앞표지 (`CoverView` Front - 라인 자물쇠 및 안내 포스트잇).
* **액션**: 포스트잇의 `[ 다이어리 열기 → ]` 클릭 ➔ 450ms 동안 앞표지만 -180도 회전.

### Frame 1: 표지 오픈 및 바닥 안착 (Cover Anchored)
* **좌측 480×640px**: 180도 뒤집힌 하드커버 안쪽 **Inside Cover** (소유자 서명란 `THIS DIARY BELONGS TO:`, `localStorage` 보존). 표지는 이후 이동하지 않고 바닥에 고정.
* **우측 480×640px**: 기록 섹션 첫 번째 흰색 속지 (`Leaf 01`).
* **우측 돌출 탭**: [기록] / [통계] / [보관] 인덱스 스티키 탭 노출.

### Frame 2: 속지 플립 (Leaf Flipping)
* **트리거**: 우측 하단 `[ 다음 장 → ]` 또는 좌측 하단 `[ ← 이전 장 ]` 클릭.
* **동작 주체**: 오직 흰색 속지 1장만 중앙 제본선 축(`transform-origin: left center`)으로 180도 회전 (400ms).
* **전이**: 우측 면 앞면 ➔ 좌측 면 뒷면으로 넘어가며 양면 스프레드 갱신.

### Frame 3: 인덱스 탭 캐스케이드 (Page Flip Cascade)
* **트리거**: 우측 돌출 인덱스 탭([통계], [보관] 등) 클릭.
* **모션**: 현재 섹션에서 넘겨져 있던 여러 장의 속지들이 50ms 간격으로 연속 회전하며 해당 섹션 첫 스프레드로 안착.

## 4. 타이포그래피 및 인라인 격줄 규격

| 영역 | 글꼴 (Font Family) | 크기 (Size) / 행간 (Leading) | 색상 (Color) |
|---|---|---|---|
| **본문 기재선 (Main Line)** | `font-handwriting` | 16px / line-height 36px | `#242220` (먹색 만년필) |
| **교정 여백선 (Correction Line)** | `font-handwriting` | 12~13px / line-height 18px | `#991B1B` (교정 잉크 레드) |
| **시스템 라벨 / 버튼** | `font-sans` (Pretendard) | 11~13px | `#57534E` / `#1C1917` |
| **타임스탬프 / 날짜 / 인덱스** | `font-mono` | 10~11px | `#78716C` |
