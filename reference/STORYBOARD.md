# STORYBOARD.md — 바인더 물리 키프레임 및 Z-Index 계층 아키텍처

> 본 문서는 M2 마일스톤의 물리적 개폐 법칙, Z-index 3D 계층 구조, 2단계 수동 인터랙션의 단계를 규정하는 정본(SSOT) 시각 스토리보드입니다.  
> 컴포넌트 코드 작성 및 수정은 반드시 본 문서에 명시된 레이아웃 및 물리 계층을 준수해야 합니다.

---

## 1. 개폐 아키텍처 개요 및 물리 불변식

1. **바인더 규격 고정**: 가로 960px × 세로 640px (1.5:1 가로형 양장 바인더).
2. **중앙 제본선 축 (Spine Axis)**: X = 480px, `transform-origin: left center` (우측 면 기준) 또는 `transform-origin: right center` (좌측 면 기준).
3. **완전 수동 2회 클릭 인터랙션 (Zero-Timer Mandate)**:
   - 자동 연쇄 타이머(`setTimeout`) 완전 폐지.
   - 1회차 클릭: 앞표지 열기 (`closed` ➔ `cover-opened`). 우측 첫 번째 흰색 내지(`LEAF 01`) 정지 노출.
   - 2회차 클릭: 첫 내지 우측 하단 "다음 장 넘기기 →" 버튼 클릭 (`cover-opened` ➔ `leaf-flipping` ➔ `opened`). 본문(PlanCard + RevisionTimeline) 안착.
4. **팝업 모달 다이얼로그 전면 폐지**: 좌측 줄노트 위에서 직접 만년필로 적는 인라인 폼(Inline Form) 채택.
5. **타이포그래피 스코핑**:
   - 시스템 메타/버튼: `font-sans` (Pretendard), 순수 영숫자/코드: `font-mono`. 한글 UI에 `font-mono` 지정 절대 금지.
   - 사용자 직접 작성 영역(소유자 서명, 계획 제목, 성공 기준 목록, 인라인 수정 필드): `font-handwriting` 강제 적용.

## 2. 4대 물리 키프레임 상세 (Keyframes)

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                               4대 키프레임 요약                                    │
│                                                                                 │
│ Frame 0: [ 데스크 메모지 (480px) ]  |  [ 닫힌 검은 앞표지 (480px) ]                  │
│                     ↓ (수동 클릭 1: "다이어리 열기 →")                                │
│ Frame 1: [ 인사이드 커버 (소유자 서명) ]  |  [ LEAF 01 표제지 (정지 대기) ]          │
│                     ↓ (수동 클릭 2: "다음 장 넘기기 →")                              │
│ Frame 2: [ 인사이드 커버 위에 내지 회전 ] ⟲ [ 우측 본문 타임라인 노출 중 ]           │
│                     ↓ (회전 완료: 450ms)                                        │
│ Frame 3: [ PlanCard (좌측 인라인 편집) ] | [ RevisionTimeline (우측 5건 이력) ]     │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### Frame 0: 닫힘 상태 (Closed)

* **상태 식별자**: `phase = 'closed'`
* **시각적 구성**:
  * **좌측 480×640px**: 웜스톤 데스크 바탕(`bg-[#EFECE6]`) 위에 얹힌 독립형 데스크 메모지(`DeskMemoSheet`). 검은 하드커버의 좌측 연장 배경은 일체 배제됨.
  * **우측 480×640px**: 닫힌 1권의 독립형 다이어리 검은 하드커버 앞표지(`CoverView` Front). 음각 영문 타이틀, 라인 자물쇠, T06-C82 안내 포스트잇 부착.
* **레이아웃 다이어그램**:

```

|   +---------------------------+   |   +---------------------------+   |
|   | [DeskMemoSheet]           |   |   | PLAN-DO-SEE DIARY         |   |

|   |                           |   |   |   | [NoticeSticky]    |   |   |
```

* **Z-Index 계층 및 물리 속성**:
  * 데스크 메모지: `z-index: 10`, `opacity: 1`, `pointer-events: auto`
  * 닫힌 앞표지 (`CoverView` Front): `z-index: 30`, `transform: rotateY(0deg)`, `pointer-events: auto`
  * 뒷단 양면 바인더 섀시 본체: `z-index: 5`, `opacity: 0`, `pointer-events: none`
  * 속지 플립 레이어 (`FlipLeaf`): `z-index: 25`, `opacity: 0` 또는 렌더링 제외

### Frame 1: 표지 열림 정지 노출 (Cover Opened & Leaf 01 Standby)

* **상태 식별자**: `phase = 'cover-opened'`
* **인터랙션 트리거**: Frame 0의 "다이어리 열기 →" 버튼 클릭 (1회차 클릭)
* **모션 전이**: 앞표지가 Y축 제본선(`left center`)을 기준으로 -180도 회전(`transform: rotateY(-180deg)`, 450ms)하여 좌측으로 완전히 안착.
* **정지 화면 구성 (타이머 없이 무한 대기)**:
  * **좌측 480×640px**: 180도 뒤집힌 하드커버 안쪽 **Inside Cover**.
    * 다이어리 소유자 서명란 ("This Diary Belongs To: [소유자 이름]").
    * `localStorage('diary_owner_name')` 실시간 양방향 바인딩.
    * 입력란: `font-handwriting` 손글씨 폰트.
  * **우측 480×640px**: 첫 번째 흰색 내지 **LEAF 01 (표제지)**.
    * 상단: `PLAN-DO-SEE | LEAF 01` 헤더.
    * 중앙: `BookOpen` 아이콘 + 손글씨 타이틀 `"기록과 성찰의 시간"` + 안내 서술문.
    * 우측 하단: **명시적 다음 장 넘김 액션 버튼 `[ 다음 장 넘기기 → ]`**.
* **레이아웃 다이어그램**:

```
+-----------------------------------+-----------------------------------+
| 좌측: Inside Cover (480px)        | 우측: LEAF 01 표제지 (480px)      |
| (하드커버 안쪽 #242220 / 안착)    | (크림색 속지 #FDFBF7, 대기 중)    |
|                                   |                                   |
|   +---------------------------+   |   +---------------------------+   |
|   | INSIDE COVER              |   |   | PLAN-DO-SEE       LEAF 01 |   |
|   |                           |   |   | ------------------------- |   |
|   | This Diary Belongs To:    |   |   |                           |   |
|   | _________________________ |   |   |       [BookOpen 아이콘]   |   |
|   | (소유자 이름 인라인 입력) |   |   |                           |   |
|   | (font-handwriting)        |   |   |     기록과 성찰의 시간    |   |
|   |                           |   |   | (계획을 펼치고 발자취를..) |   |
|   | [ 표지 다시 닫기 ]        |   |   |                           |   |
|   |                           |   |   |                           |   |
|   |                           |   |   |                           |   |
|   | "생각을 기록하고..."      |   |   |   [ 다음 장 넘기기 → ]    |   |
|   +---------------------------+   |   +---------------------------+   |
+-----------------------------------+-----------------------------------+
```

* **Z-Index 계층 및 물리 속성**:
  * 펼쳐진 앞표지 (`CoverView` Back / Inside Cover): `z-index: 20`, 좌측 배치(`transform: rotateY(-180deg)`), `pointer-events: auto`
  * 첫 번째 속지 (`FlipLeaf` Front / LEAF 01): `z-index: 25`, 우측 배치(`transform: rotateY(0deg)`), `pointer-events: auto`
  * 우측 아래 깔린 본문(타임라인): `FlipLeaf`에 완전히 덮여 시각적으로 노출되지 않음.
  * 데스크 메모지: `opacity: 0`, `pointer-events: none`

### Frame 2: 내지 플립 전이 (Leaf Flipping Transition)

* **상태 식별자**: `phase = 'leaf-flipping'`
* **인터랙션 트리거**: Frame 1 우측 하단의 `[ 다음 장 넘기기 → ]` 버튼 클릭 (2회차 클릭)
* **모션 전이**:
  * 오직 우측의 흰색 내지 1장(`FlipLeaf`)만 중앙 제본선 축(`transform-origin: left center`)으로 왼쪽으로 180도 회전 전이(`rotateY(0deg) ➔ rotateY(-180deg)`, 450ms `cubic-bezier(0.2, 0, 0.2, 1)`).
  * 검은색 하드커버는 바닥에 완전 고정되어 미동도 하지 않음.
* **전이 중 시각적 효과**:
  * 0° ➔ 90°: LEAF 01 표제지가 들리면서 우측 본문의 `RevisionTimeline`이 드러남.
  * 90° ➔ 180°: 속지의 뒷면(Page 01 빈 면 또는 전환 면)이 좌측 인사이드 커버 위로 덮여 내려앉음.
* **레이아웃 다이어그램**:

```
+-----------------------------------+-----------------------------------+
| 좌측: Inside Cover 위로 내지 안착 | 우측: 본문 타임라인 점진 노출    |
|                                   |                                   |
|   +-------------+       /         |   +---------------------------+   |
|   | Inside Cover|      /          |   | TIMELINE VIEWER           |   |
|   |             |     / [회전 중] |   | ------------------------- |   |
|   | (내지가     |    /  내지 1장  |   | [M2 수정 이력 타임라인    |   |
|   |  덮여 내려옴)   /  (450ms)    |   |  5건 단위 목록 노출 시작] |   |
|   |             |  /              |   |                           |   |
|   +-------------+ /               |   +---------------------------+   |
+-----------------------------------+-----------------------------------+
```

* **Z-Index 계층 및 물리 속성**:
  * 회전 중인 내지 (`FlipLeaf`): `z-index: 35`, 3D 회전 구동 중, 조작 방지를 위해 `pointer-events: none`
  * 하단 양면 바인더 본체: `z-index: 10`, `opacity: 1` 활성화
  * 표지 (`CoverView`): 좌측 바닥에 위치, `z-index: 5`

### Frame 3: 본문 안착 및 완전 개방 (Opened / Content Active)

* **상태 식별자**: `phase = 'opened'`
* **안착 화면 구성**:
  * **좌측 480×640px**: 활성 계획 카드 **`PlanCard`**.
    * 줄노트 배경 위 인라인 편집 폼(Inline Form).
    * `isEditing` 토글에 따라 읽기 모드 / 인라인 수정 모드 즉시 전환 (팝업 모달 다이얼로그 없음).
    * 제목, 성공 기준 줄노트 항목, 인라인 수정 입력란에 `font-handwriting` 손글씨 폰트 적용.
    * 좌측 하단: "표지 닫기" 버튼 (닫기 클릭 시 역방향 전이 시작).
  * **중앙 16px**: `SpineDivider` (금속 링 / 제본선 그라디언트 및 안쪽 음영).
  * **우측 480×640px**: 수정 이력 타임라인 **`RevisionTimeline`**.
    * 무스크롤 5건 타임라인 (상하단 페이지네이션 인덱스).
    * 변경 전 값 취소선(`line-through`) 및 변경 후 값 대조 인라인 렌더링.
* **레이아웃 다이어그램**:

## 4. 인터랙션 및 타이포그래피 구현 상세 규격

### 4.1 상태 전이 핸들러 규격 (`BinderChassis`)
* **타입 정의**:
  ```typescript
  type BinderPhase =
    | 'closed'         // Frame 0
    | 'cover-opening'  // 표지 회전 전이 (450ms)
    | 'cover-opened'   // Frame 1: LEAF 01 정지 노출
    | 'leaf-flipping'  // Frame 2: 속지 회전 전이 (450ms)
    | 'opened'         // Frame 3: 본문 양면 상호작용
    | 'closing-leaf'   // 역순 닫기: 속지 되덮기 (350ms)
    | 'closing-cover'; // 역순 닫기: 표지 덮기 (450ms)
  ```
* **수동 트리거 함수**:
  * `handleOpenCover()`: `closed` ➔ `cover-opening` ➔ (450ms) ➔ `cover-opened` (자동으로 다음 장으로 안 넘어감!)
  * `handleFlipLeaf()`: `cover-opened` ➔ `leaf-flipping` ➔ (450ms) ➔ `opened`
  * `handleCloseCover()`: `opened` ➔ `closing-leaf` ➔ (350ms) ➔ `closing-cover` ➔ (450ms) ➔ `closed`

### 4.2 인사이드 커버 소유자 서명란 (`CoverView`)
* **스토리지 키**: `localStorage.getItem('diary_owner_name')` / `setItem`
* **UI 구조**:
  * 라벨: `"This Diary Belongs To:"` (`font-mono text-stone-400 text-xs`)
  * 입력란: 단선 언더라인 스타일(`border-b border-stone-500 bg-transparent text-stone-200 outline-none w-full px-1 py-1 text-base font-handwriting`)
  * 플레이스홀더: `"이름을 서명하세요"`
  * 하단 액션: `"표지 다시 닫기"` 링크형 버튼 제공 (실수로 표지만 열었을 때 바로 닫을 수 있는 배려).

### 4.3 인라인 편집 줄노트 폼 (`PlanCard`)
* **팝업 모달 다이얼로그 전면 제거**:
  * 기존 `isEditModalOpen` 및 `<div className="fixed inset-0 ...">` 모달 마크업 완전 삭제.
* **인라인 편집 모드 (`isEditing`)**:
  * 계획 카드 상단 `[수정]` 버튼 클릭 시, 카드 전체가 줄노트 폼으로 인라인 전환.
  * 입력 필드(제목, 성공 기준 텍스트)에 `font-handwriting` 적용.
  * 종이 배경과 일체화된 언더라인 또는 옅은 박스 인풋:
    * 제목 입력: `border-b border-stone-300 bg-transparent font-handwriting text-lg text-stone-900 focus:border-stone-800`
    * 성공 기준 항목: 각 줄마다 체크박스 + 인라인 손글씨 인풋 + 우측 미세 삭제(`X`) 아이콘.
    * 하단 버튼: `[저장]` / `[취소]` 인라인 배치.
