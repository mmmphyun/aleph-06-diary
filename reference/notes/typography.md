# TYPOGRAPHY.md — 타이포그래피 및 폰트 스코핑 규칙

> 시스템 UI의 판독성 및 정렬 무결성과, 다이어리 특유의 손글씨 감성을 공존시키기 위해 **"시스템 UI 영역"**과 **"사용자 필기 영역"**을 엄격히 분리(Scoped Typography)합니다.

---

## 1. 폰트 분류 및 파일 매핑

| 분류 | 폰트 종류 | 소스 파일 위치 | 용도 및 성격 |
|---|---|---|---|
| **시스템 폰트 (System UI)** | Inter / Pretendard / JetBrains Mono | 웹폰트 / 시스템 기본 | 숫자, 날짜, 정렬 기준 배너, 버튼, 탭 라벨, 시스템 오류 메시지 |
| **손글씨 폰트 1 (Child)** | 어린아이 글씨체 | `reference/fonts/child.ttf` | 사용자 필기 영역 (자유롭고 둥글둥글한 느낌) |
| **손글씨 폰트 2 (Adult)** | 어른 글씨체 | `reference/fonts/adult.ttf` | 사용자 필기 영역 (단정하고 각이 살아있는 어른 필기체) |
| **손글씨 폰트 3 (Normal)** | 일반 필기체 (기본값) | `reference/fonts/normal.ttf` | 사용자 필기 영역 (가장 무난하고 자연스러운 일상 손글씨) |

## 2. 영역별 스코핑(적용) 원칙

### 2.1 시스템 & 데이터 영역 (절대 손글씨체 적용 금지)
* **적용 클래스**: `font-sans` 또는 `font-mono`
* **적용 대상**:
  * 마감일시, 타임스탬프 (`2026-10-31 23:30`, `YY.MM.DD HH:mm`)
  * 시간량 숫자 및 단위 (`90분`, `±15분`)
  * 정렬 공시 배너: `"정렬 기준: 마감일 오름차순 → 우선순위(높음 우선) → 제목 가나다순 → ID순"`
  * 상태 스티커 텍스트 (`진행 전`, `진행 중`, `완료`)
  * 탭 라벨, 헤더 버튼, 모달 닫기/저장 버튼 라벨
  * 시스템 에러 메시지
* **이유**: 숫자/기호 판독성 보장(T06-C35) 및 테이블/카드 그리드 정렬 어긋남 방지(T06-C20).

### 2.2 사용자 필기 영역 (선택된 손글씨 폰트 적용)
* **적용 클래스**: `font-handwriting`
* **적용 대상**:
  * 계획 제목 및 성공 기준 텍스트 (T06-C06)
  * 할 일 제목 및 본문 설명문 (T06-C10)
  * 실행 기록의 '막혔던 이유(Blocker Reason)' 서술문 (T06-C26)
  * 표지 자물쇠 하단 안내 포스트잇 문구 (T06-C82)
* **이유**: 종이 질감 위에서 실제 펜으로 꾹꾹 눌러 쓴 듯한 다이어리 본래의 정체성 부여.

## 3. 사용자 폰트 선택(Picker) 및 상태 보존
* **선택 UI**: 다이어리 상단 바인더 모서리에 작은 펜촉 토글(`[ 펜 선택: 일반 ▾ ]`) 제공.
* **보존 위치**: 브라우저 `localStorage.getItem('diary_font_preference')`.
* **성능 제약**: CSS 선언 시 `font-display: swap;` 필수 적용으로 텍스트 깜빡임 방지.
