# DO-NOT-COPY.md — 안티패턴 및 금지 설계 목록

> 에이전트 코딩 시 아래 패턴을 하나라도 채택할 경우 즉시 실패 판정(Reject)합니다.

---

### 1. 키치한 스큐어모피즘 클리셰 (Skeuomorphic Cliches)
* **금지: 사실적인 가죽 질감 / 스티치 / 거친 나무 책상 배경**
  * 인조가죽(Skeuomorphic leather) 텍스처 이미지나 굵은 바느질 스티치 그래픽 사용 금지.
  * 채도 높은 번들거리는 원목 텍스처 배경 금지. 무광 매트 웜스톤(`bg-[#EFECE6]`)만 허용.
* **금지: 3D 금속 자물쇠 클립아트 / 장난감 열쇠**
  * 3D 렌더링된 번들거리는 금속 자물쇠 이미지 금지.
  * 정교한 2px 단색 라인 아웃라인 아이콘(`lucide: LockKeyholeOpen`)만 허용.
* **금지: 채도 높은 샛노란 포스트잇 (Post-it)**
  * 오피스 3M 스타일의 형광 노란색 금지. 페일 크림 옐로우(`bg-[#FFFDE7]` / `border-amber-200/60`)만 허용.
* **금지: 찢어진 종이/구겨진 종이 비트맵 이미지**
  * 이미지 스프라이트를 쓰지 말고, CSS `clip-path` 및 미묘한 1px 대시 보더(`border-dashed`)로만 추상화하여 표현할 것.

---

### 2. 전형적인 기업형 SaaS 플랫 대시보드 (Generic Corporate Flat)
* **금지: 보라색/파란색 원색 그라디언트 및 사이드바**
  * 좌측에 흔한 검은색 어드민 사이드바를 두고 우측에 흰색 카드들을 늘어놓는 어드민 템플릿(Admin Dashboard) 형태 금지.
  * 반드시 양면 펼침 다이어리 바인더(Book Binder) 형태를 유지할 것.
* **금지: 번들거리는 차트 라이브러리 남용**
  * 화려한 3D 도넛 차트, 네온 컬러 꺾은선 그래프 금지. 정갈한 흑백/단색 막대 및 텍스트 중심의 에디토리얼 레이아웃 유지.

---

### 3. 인터랙션 및 프런트엔드 안티패턴
* **금지: WebGL / Three.js 등 무거운 3D 런타임 도입**
  * 무거운 3D 라이브러리 사용 전면 금지. 순수 CSS 3D Transforms (`perspective`, `rotateY`, GPU 하드웨어 가속)로만 구현.
* **금지: `dangerouslySetInnerHTML` 사용 (T06-C57 위반)**
  * 사용자 입력 텍스트를 HTML로 직접 파싱하는 코드는 XSS 보안 결함이므로 일체 금지.
* **금지: 페이지 회전 중 폼 입력 포커스 방치**
  * 3D 책장이 넘어가는 동안 텍스트 인풋이 눌려 클릭 좌표가 어긋나지 않도록 회전 중 포커스/클릭을 비활성화할 것.
