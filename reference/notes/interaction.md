# INTERACTION.md — 2.5D 인터랙션 및 물리 전이 명세

## 1. 물리 개폐 및 네비게이션 인터랙션

### 1.1 앞표지 최초 1회 오픈 (Cover Unfold)
* **트리거**: 닫힌 앞표지 안내 포스트잇의 `[ 다이어리 열기 → ]` 클릭.
* **동작**: 검은 앞표지만 `transform: rotateY(-180deg)` (450ms).
* **결과**: 좌측 바닥(Inside Cover - 소유자 서명란)에 영구 고정. 이후 모든 페이지 넘김에서 앞표지는 움직이지 않음.

### 1.2 속지 단독 플립 (Single Leaf Flip)
* **트리거**: 우측 하단 `[ 다음 장 → ]` 또는 좌측 하단 `[ ← 이전 장 ]` 클릭.
* **동작 주체**: 오직 흰색 속지 1장만 중앙 제본선(`transform-origin: left center`)을 축으로 180도 회전 (400ms `cubic-bezier(0.2, 0, 0.2, 1)`).
* **방어 로직**: 회전 중에는 `pointer-events-none` 적용하여 클릭 좌표 튐 방지.

### 1.3 인덱스 탭 캐스케이드 플립 (Page Flip Cascade)
* **트리거**: 우측 돌출 인덱스 탭([기록] / [돌아보기] / [보관함]) 클릭.
* **동작**: 현재 섹션에서 넘겨진 속지들이 50ms 시차를 두고 연속 회전하여 목표 섹션의 첫 번째 스프레드를 노출.

## 2. 기록 및 교정 인터랙션

### 2.1 아날로그 인라인 취소선 교정 (In-place Strikethrough Edit)
* **트리거**: 본문 기재선에서 수정할 텍스트 구간을 마우스로 드래그 선택 ➔ `[수정]` 확인 팝업 버튼 클릭.
* **모션 및 시각 변화**:
  - 선택된 원문 텍스트에 만년필 손글씨 취소선(`line-through`) 렌더링.
  - 해당 줄 바로 아래의 18px 교정 여백선에 버건디 레드(`#991B1B`) 인라인 인풋 필드 활성화.
  - 입력 완료(`Enter` 또는 `onBlur`) 시 수정 텍스트가 영구 고정됨.
* **제약**: 수정은 항목당 최대 1회로 한정 (아날로그 다이어리 교정 메타포). 하단 텍스트는 일체 밀려나지 않음.

### 2.2 할 일 템플릿 삽입 및 실행 기록 연쇄 인터랙션
* **할 일 템플릿 삽입**: 계획 캔버스가 끝난 후 `[+ 새 장 넘겨 할 일 작성]` 클릭 시, 새로운 빈 속지가 넘어가며 체크리스트 템플릿 배치.
* **실행 기록 연쇄 기록**:
  - 유저가 할 일 체크박스를 완료(`checked`)하면, 실행 일지 속지의 빈 줄에 `[YY.MM.DD HH:mm] 완료: 할 일 제목` 잉크 타임스탬프와 한 줄 코멘트 인풋이 실시간으로 새겨짐.
