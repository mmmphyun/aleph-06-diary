# INTERACTION.md — 2.5D 인터랙션 및 물리 개폐 명세

> 모든 3D 회전과 움직임은 GPU 합성 스레드(Compositor Thread)에서 실행되도록 `transform`과 `opacity`만 제어합니다.  
> 자동 연쇄 타이머에 의한 임의 화면 전환을 전면 금지하며, 물리적 조작감은 사용자의 명시적 수동 입력에 의해 트리거됩니다.

---

## 1. 2단계 수동 북 플립 (Two-Stage Manual Book Flip)

실제 양장본 책의 물리적 개폐 법칙을 충족하고 시각적 인지 부하를 해소하기 위해 **자동 연쇄 타이머(`setTimeout`)를 전면 폐지**하고, **명시적 2회 수동 클릭 인터랙션**을 적용합니다.

```
[Frame 0: 닫힘] ➔ (수동 클릭 1: 표지 열기) ➔ [Frame 1: 표제지 정지 대기] ➔ (수동 클릭 2: 다음 장 넘기기) ➔ [Frame 3: 본문 안착]
```

### 1.1 [수동 클릭 1] 앞표지 열기 (Cover Unfold)
* **트리거**: Frame 0 우측 표지 안내 포스트잇의 `"다이어리 열기 →"` 버튼 클릭.
* **동작 주체**: 검은색 하드커버 앞표지(`CoverView`) 단독 회전.
* **회전 축**: 중앙 제본선 축 (`transform-origin: left center`).
* **변환 속성**: `transform: rotateY(-180deg)`
* **지속 시간 및 이징**: `450ms cubic-bezier(0.2, 0, 0.2, 1)`
* **정지 화면 (Frame 1)**:
  * 좌측: 180도 뒤집혀 안착한 하드커버 안쪽 **Inside Cover** (소유자 서명 입력 폼).
  * 우측: 첫 번째 흰색 내지 **LEAF 01 (표제지)** 정지 노출.
  * **불변식**: 사용자가 후속 클릭을 할 때까지 자동 전환 없이 무한 정지 대기.

### 1.2 [수동 클릭 2] 첫 내지 넘기기 (Leaf Flip)
* **트리거**: Frame 1 우측 LEAF 01 표제지 하단의 `[ 다음 장 넘기기 → ]` 버튼 클릭.
* **동작 주체**: 오직 우측의 흰색 내지 1장(`FlipLeaf`)만 단독 회전 (검은색 표지는 좌측 바닥에 완전 고정).
* **회전 축**: 중앙 제본선 축 (`transform-origin: left center`).
* **변환 속성**: `transform: rotateY(-180deg)`
* **지속 시간 및 이징**: `450ms cubic-bezier(0.2, 0, 0.2, 1)`
* **방어 로직**: 회전 중(`phase === 'leaf-flipping'`)에는 `pointer-events-none` 적용하여 입력 좌표 어긋남 방지.
* **완료 화면 (Frame 3)**:
  * 좌측: 활성 계획 카드 `PlanCard` (줄노트 인라인 편집 지원).
  * 우측: 수정 이력 타임라인 `RevisionTimeline` (5건 페이징).
  * 회전 내지(`FlipLeaf`)는 `hidden` 처리되어 본문 클릭/포커스를 차단하지 않음.

### 1.3 다이어리 닫기 (Book Fold)
* **트리거**:
  * Frame 3 (본문 개방 시): 좌측 하단 `[ 표지 닫기 ]` 버튼.
  * Frame 1 (표지만 열린 시): 좌측 Inside Cover 상단 `[ 표지 닫기 ]` 버튼.
* **전이 단계**:
  * Frame 3에서 닫기:
    1. 1단계: 흰색 내지만 우측으로 되덮기 (`rotateY(0deg)`, 350ms).
    2. 2단계: 검은색 앞표지가 우측으로 되덮이며 닫힘 완료 (`rotateY(0deg)`, 450ms).
  * Frame 1에서 닫기: 검은색 앞표지만 우측으로 되덮여 닫힘 완료 (450ms).

## 2. 폼 및 에디토리얼 인터랙션

### 2.1 인라인 계획 편집 (Inline Form Interaction)
* **팝업 모달 다이얼로그 전면 폐지**: 다이어리 종이 위에 직접 만년필로 적는 아날로그 메타포 유지를 위해 SaaS 플로팅 모달 배제.
* **인라인 전환 (`isEditing`)**:
  * 계획 카드 상단 `[계획 수정]` 버튼 클릭 시, 카드 전체가 줄노트 인라인 편집 폼으로 즉시 전환.
  * 제목 및 성공 기준 항목에 `font-handwriting` 손글씨 인풋 즉시 활성화.
  * 줄노트 위에서 실시간 항목 추가(`Enter` / `+추가`), 삭제(`Trash2`), 수정 수행.
  * `[저장]` 클릭 시 `planService.updatePlan()` 호출 후 읽기 모드로 복귀 및 우측 타임라인 실시간 갱신.
  * `[취소]` 클릭 시 변경사항 폐기 후 원본 데이터로 복귀.

### 2.2 소유자 서명 입력 (Inside Cover Signature)
* **트리거**: Inside Cover의 언더라인 텍스트 필드 포커스 및 입력.
* **동기화**: `onChange` 이벤트 발생 시 브라우저 `localStorage.setItem('diary_owner_name', value)`로 즉시 영구 보존.
* **스타일**: 종이에 직접 잉크로 서명하듯 단선 언더라인 및 `font-handwriting` 손글씨 폰트 적용.

## 3. 상태 인터랙션

* **성공 기준 체크 토글**:
  * 줄노트 항목 클릭 시 체크박스(`CheckSquare` / `Square`) 전환 및 텍스트 취소선(`line-through`) 토글.
* **타임라인 페이징 (Revision Timeline)**:
  * 하단 이전/다음 페이지 버튼 클릭 시 5건 단위 무스크롤 인덱스 전환.
  * 변경 전 값 취소선(`line-through`) 및 변경 후 값 대조 인라인 표시.
* **할 일 완료 (Stamp Spring)**:
  * 완료 버튼 클릭 시 `scale(0.9) -> scale(1.05) -> scale(1)` 스프링 햅틱 (250ms `cubic-bezier(0.34, 1.56, 0.64, 1)`).
* **저장 중 (Nib Pulse)**:
  * 만년필 닙 좌우 흔들림 애니메이션 (1s loop).
* **오류 발생 (Coffee Splash)**:
  * 반투명 커피 링 워터마크 배경 + 고대비 에러 박스 및 재시도 버튼 (400ms).
