# ACCESSIBILITY.md — 웹 접근성 및 보안 무결성 가이드

## 1. 텍스트 판독성 및 고대비 보장 (WCAG 2.1 AA)
* **시스템 데이터 영역**:
  * 마감일시, 시간 차이, 정렬 배너, 상태 텍스트는 손글씨체가 아닌 고대비 시스템 폰트(`font-mono` / `font-sans`)를 사용하여 배경과의 명도 대비 4.5:1 이상 유지.
* **손글씨 폰트 영역**:
  * 크림색 속지(`bg-[#FDFBF7]`) 위에서 텍스트 색상(`text-[#1C1917]` 또는 `#3A3632`)을 짙게 유지하여 가독성 저하 방지.

## 2. 보안 렌더링 무결성 (T06-C57 원천 방어)
* **DOM Text Node 렌더링 강제**:
  * 사용자가 입력한 모든 문자열(계획 제목, 설명, 할 일 제목, 성공 기준, 막혔던 이유 등)은 React 기본 바인딩 `{text}`로만 출력.
  * `dangerouslySetInnerHTML`의 사용을 프로젝트 전역에서 원천 금지.
  * `<script>alert(1)</script>` 등의 XSS 공격 구문이 입력되더라도 스크립트 실행 없이 텍스트 문자열 그대로 렌더링됨을 보장.

## 3. 키보드 인터랙션 및 포커스 관리
* **3D 책장 회전 중 포커스 방어**:
  * 책장이 `rotateY(-180deg)`로 회전하는 동안(`pointer-events-none`) 폼 인풋 및 버튼의 포커스를 비활성화하여 좌표 불일치 및 오입력 차단.
* **포커스 링**:
  * 모든 대화형 요소(탭, 버튼, 입력창)는 키보드 탐색 시 `:focus-visible` 아웃라인(`outline-2 outline-offset-2 outline-stone-400`)을 명확히 노출.
* **스크린 리더 배려**:
  * 아이콘 전용 버튼(잠금쇠, 펜촉, 닫기, 휴지통, 날짜 선택기)에는 `aria-label`을 필수로 선언.
